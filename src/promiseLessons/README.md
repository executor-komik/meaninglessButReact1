# Promise and fetch lessons

Promise and async lessons integrated into the main React app (lessons 1–6).

## Open

```bash
npm install
npm run dev
```

Open the main app and select **API Again** to view the lessons.

## Tests

```bash
bun test src/promiseLessons/lessons
```

## Lessons

| # | What |
|---|------|
| 1 | `new Promise` — `src/lessons/lesson-01-first-promise/` |
| 1b–4 | `.then`, `.catch`, `async/await`, `Promise.all`, `allSettled` — `DelayedMessageDemo` |
| 5 | `fetch` Open‑Meteo weather |
| 6 | Geocode a city, then weather |
